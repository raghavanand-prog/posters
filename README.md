# Quishing Awareness Demo

**An interactive walk-through of a QR-code phishing scam ("quishing"), built for Cybersecurity Awareness Week.**

Why it exists: QR codes hide where they lead, which makes them an easy trap on posters, flyers and parcels. Walking through the attack helps people recognise it.

**Try it:** download the repository and open `index.html` in any browser. It runs entirely in your browser and needs nothing else.

> ⚠️ **Educational demo.** "Nyvora" is a fictional brand. The form **never submits, stores, logs or transmits** anything: there is no backend, no storage and no network calls.

## What it shows
1. A realistic-looking store homepage
2. A simulated "QR scan" redirect to a spoofed rewards page offering a too-good-to-be-true discount
3. A fake sign-up form, the step where a real attack would harvest credentials
4. A reveal screen that explains the red flags to watch for

## Responsible use
For awareness training only. Do not repurpose it to target real users or impersonate real brands.
